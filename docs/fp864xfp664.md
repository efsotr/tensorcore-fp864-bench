# Curated FP864 x FP664 benchmark

`tensorcore-fp864x-fp664-bench` is a deliberately small dense-only benchmark for practical mixed low-precision cases on SM120.

Here `FP864 x FP664` means the left operand is sampled from the FP8/FP6/FP4 family while the right operand is restricted to the two FP6 encodings (`e3m2`, `e2m3`) and FP4 (`e2m1`). It is not intended to enumerate the full Cartesian product.

The executable uses an explicit 20-case allowlist from the canonical manifest:

- 10 unscaled `kind::f8f6f4` cases with F32 accumulation;
- 7 `kind::mxf8f6f4.block_scale` cases using the explicit `ue8m0 + scale_vec::1X` spelling;
- 1 MXFP4 `ue8m0 + 2X` reference;
- 2 NVFP4 references using `ue8m0 + 4X` and `ue4m3 + 4X`.

It intentionally excludes:

- all sparse MMA;
- F16 accumulation;
- legacy FP8-only cases;
- duplicate omitted-default block-scale spellings;
- `--all-operands` selector expansion;
- documentation-ambiguous and undocumented probes.

Build both benchmarks normally:

```bash
cmake -S . -B build
cmake --build build -j
```

List the curated cases without requiring a GPU:

```bash
./build/tensorcore-fp864x-fp664-bench --list
```

Run the curated benchmark:

```bash
./build/tensorcore-fp864x-fp664-bench
```

The normal timing controls remain available, for example:

```bash
./build/tensorcore-fp864x-fp664-bench \
  --iters 4000 \
  --blocks-per-sm 4 \
  --chains 8 \
  --repeats 5
```

`--filter TEXT` may further narrow the allowlist. `--include-probes`, `--probes-only`, and `--all-operands` are rejected because they contradict the purpose of this curated suite.

## Output

A normal timing run prints per-case PASS/FAIL records followed by a compact four-family peak table. It also persists the same run under:

```text
results/<UTC timestamp>_<GPU>_fp864x_fp664/
  cases.log
  result.json
```

`cases.log` preserves the human-readable per-case output. `result.json` is the complete machine-readable result and includes device metadata, timing configuration, every selected case, pass/fail counts, and the best measured TFLOP/s for `unscaled_f8f6f4`, `mxf8f6f4`, `mxf4`, and `mxf4nvf4`.

Use `--quiet-cases` to suppress per-case terminal output while still writing `cases.log`. Use `--output-dir DIR` to override the default run directory.
